
# Projeto de Desenvolvimento Web - Matheus Nunes

## Sobre o projeto

Este projeto foi desenvolvido como atividade acadêmica do curso de Análise e Desenvolvimento de Sistemas.

O objetivo é criar um site pessoal utilizando HTML e CSS, apresentando informações profissionais, conteúdos sobre tecnologia, uma galeria de fotos e um formulário de contato.

## Páginas do site

- **Início:** apresentação do site.
- **Currículo:** informações pessoais, formação e experiências profissionais.
- **Blog:** conteúdos relacionados à tecnologia e desenvolvimento web.
- **Fotos:** galeria com imagens de tecnologia e hobbies.
- **Contato:** formulário para comunicação.

## Tecnologias utilizadas

- HTML5
- CSS3
- Visual Studio Code
