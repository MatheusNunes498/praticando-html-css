O que é desenvolvimento Front-end?

O desenvolvimento Front-end é a área responsável pela parte visual de um site ou aplicação, ou seja, tudo aquilo que o usuário consegue visualizar e utilizar.

Para desenvolver páginas web, algumas das principais tecnologias utilizadas são HTML, CSS e JavaScript.

Principais tecnologias

  • HTML: responsável pela estrutura da página.
  • CSS: responsável pela aparência e estilização.
  • JavaScript: adiciona interatividade às páginas.

Aprender essas tecnologias é um dos primeiros passos para quem deseja trabalhar com desenvolvimento web.
